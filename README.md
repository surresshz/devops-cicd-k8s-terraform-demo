# DevOps CI/CD + Kubernetes + Terraform Demo

This project demonstrates an end-to-end DevOps pipeline:

- Python Flask application
- Docker containerization
- CI/CD using GitLab CI
- Kubernetes deployment
- Infrastructure provisioning using Terraform (AWS)

## Workflow
1. Code pushed to GitLab
2. CI/CD pipeline builds Docker image
3. Image deployed to Kubernetes cluster
4. Infrastructure managed via Terraform

## Tech Stack
Python | Docker | Kubernetes | GitLab CI | Terraform | AWS

## Outcome
- Automated deployments
- Scalable containerized app
- Infrastructure as Code setup
